# 宝宝学习角

给学前小朋友玩的学习小游戏，纯 HTML 页面，不需要安装和编译，用浏览器直接打开 `index.html` 就能玩。

## 页面

- `index.html`：首页，进入三个游戏
- `shapes.html`：**Shapes 认形状**。2D 平面图形 16 个（含五边形到十边形），3D 立体图形 9 个（含四面体）。翻卡片看英文和中文，有一次一张的测试。
- `phonics.html`：**Phonics 自然拼读**。5 个短元音 + 21 个辅音，可以先学元音，也可以按 s a t i p n 混着学。
  - 学习：每个音 3 个配图例词，可以把图片先藏起来，先读字再看图
  - 听音游戏：不看字母，找开头音一样的图片
  - 拼读：只用孩子学过的字母拼 CVC 单词（s‑a‑t → sat）
  - 测试：看图选字母、听词选图、看字母说发音
- `hanzi.html`：**认汉字**。按孩子字帖的顺序，两个字一对：先是一到十（一 二、三 四……九 十），再是多 少、水 火、山 石、日 月、了 个，一共 20 个字。
  - 数字用苹果来数（五个一排，方便数 8 和 9）；看字选图测试里数字只和数字一起出题
  - 学习：田字格里看笔顺动画，点“跟着写”用手指描（写错两次会提示下一笔）；每个字一张图、3 个配图词语和家长怎么教
  - “了”和“个”画不出来，用例句（下雨了、一个苹果）和数东西来教，不进看字选图的测试
  - 可以选“学到哪一对了”，测试只考学过的字
  - 测试：看字选图、听音找字、认字卡

## 说明

- 单词读音用浏览器自带的语音合成（Web Speech API），不同设备声音不同。
- 单独的字母音还没有音频，页面上用音标和中文口型提示代替。
- 字体从 Google Fonts 加载，离线时会用系统字体代替。
- 汉字页的读音用中文语音（zh-CN），读成“水，喝水的水”这样，免得单字读错音（比如“了”）。
- 笔顺和描红用 [Hanzi Writer](https://github.com/chanind/hanzi-writer)，库和笔画数据放在 `vendor/hanzi-writer/`，不用联网。加新字的方法见那里的 README。
